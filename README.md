# LX Music 收藏同步（lx-favorites-sync）

一个 Folia 模组：把 **LX Music 的「我喜欢」** 自动同步到 **Folia 的本地收藏（Liked Songs）**。

它**不下载、不搬运音乐文件**：LX 的「我喜欢」是数据源，模组负责把它与你**已有的本地音乐文件**精确匹配，匹配到的歌曲才会写进 Folia 收藏。

> 作者：xiaomo521314 × 吃白饭的蓝色大肥鱼 ｜ 许可证：MIT

## 特性

- 不上传任何数据、不发起任何网络请求、不常驻后台、不设置开机自启。
- 只同步“本地确实存在”的歌曲：直接从 Folia 本地曲库匹配。
- 歌名、歌手、时长三字段精确匹配；同名不同版本（Live、伴奏、重制等）不会互相误配。
- 新歌入库依赖 Folia 自带的本地扫描：用 Folia 的「重新扫描」或开启「自动扫描本地文件夹」即可（模组不会代替 Folia 扫描目录，也不调用 Folia 的内部接口）。
- 内置「本地缺失」面板：列出没有匹配到本地文件的收藏，并标注哪些是“已下载但还没被 Folia 收录”，对症给出提示。
- 「同步历史」：每次收藏变化都会记录（时间、新增 / 移除明细），可在模组设置里任选一条回退。
- 播放器进度条旁有「一键同步」按钮：点一下立即同步，悬停可看上次同步结果。
- 两种模式：`完全同步`（以 LX 为准）与 `只增加`（只追加不删除），在模组面板的「同步设置」里直接选择。

## 安装

### 从模组市场安装（推荐）

在 [Folium 模组市场](https://folium-compound.cielaniska.top/) 搜索 `lx-favorites-sync`，把下载的 zip 拖进 Folia 的模组面板即可。

### 手动安装

1. 打开 Folia →「设置 → 实验室」，开启模组系统。
2. 把 `lx-favorites-sync` 文件夹压缩成 zip（zip 顶层就是这个文件夹），拖进 Folia 的「模组管理」面板；也可以直接把该文件夹复制进 `%APPDATA%\Folia\mods\`。
3. 启用「LX Music 收藏同步」，并在确认弹窗中确认一次。

如果 LX 的下载目录还没有导入 Folia：在 Folia 的「本地音乐」页面把它导入一次。建议再开启设置里的「自动扫描本地文件夹」，这样以后 LX 下载的新歌会被 Folia 自动收录。

## 使用

Folia 命令面板（`Ctrl+K`）中的命令：

| 命令 | 作用 |
| --- | --- |
| `同步 LX Music 收藏` | 立即手动同步一次 |
| `恢复最近一次变化前的收藏` | 回退到最近一次收藏变化之前（只动收藏歌单） |
| `查看本地缺失歌曲` | 打开「本地缺失」面板 |

同步模式、上次同步结果与「同步历史」都在 Folia 模组面板的「同步设置」里：展开「LX Music 收藏同步」，可直接切换同步模式；展开「同步历史」可以看到每次收藏变化的记录（时间、触发方式、`+N / -M`，点开带歌曲明细），每条都能单独回退。回退需要点击两次确认，不会误触。

播放器面板中还有「本地缺失」标签页，支持按歌名 / 歌手 / LX 原顺序排序，并可一键重新同步。
播放器进度条右侧还有一个「同步」图标按钮：单击立即同步（悬停显示上次同步结果）。

## 缺失提示说明

「本地缺失」面板会给出两类标记：

- **已下载未收录**：LX 下载记录里这首歌的文件确实存在，但 Folia 曲库里还没有 → 多半是下载目录还没被 Folia 扫描，去「本地音乐」重新扫描对应目录即可。
- **疑似在下载目录**：LX 下载目录里存在文件名同时包含歌名与歌手的文件 → 可能只是还没入库，也可能是另一个版本。

## 匹配规则

- **歌名、歌手**：NFKC 规范化（全半角统一）、忽略大小写与标点空格、去掉 `feat.` 附注后，必须完全相等。
  版本字样（如 `(Live)`、`-insturmental`）保留在歌名里参与比较，因此不会与普通版本互配，也不需要维护“后缀词表”。
- **时长**：LX 记录为 `mm:ss` 整秒，必须等于本地文件时长的**截断值**或**四舍五入值**（两者必居其一，无容差区间）。
  例如 LX 04:06（246 秒）与 246.7 秒的文件一致；与 250 秒的文件不一致，会显示为缺失而不是乱配。
- 匹配优先取文件元数据，其次取文件名 / 标题中的 `歌名 - 歌手` 字段。

## 原理与数据

**读取**

- LX Music 数据库 `lx.data.db`：`my_list_music_info`（`listId = 'love'`）、`download_list`、`config_v2.json` 中的下载目录设置。全程只读，不写入 LX 的任何文件。
- Folia 的 IndexedDB（`KineticPlayerDB`）：本地曲库 `local_music`、收藏歌单 `local_playlists`（只读）。
- LX 下载目录：仅列出音频文件名（用于缺失提示），不读取文件内容。

**写入**

- Folia 的收藏歌单（`local_playlists` 里 `isFavorite` 的那一条）：只改 `songIds`，用于同步与回退——这是模组的核心功能。
- 模组专属数据目录 `%APPDATA%\Folia\mods-data\lx-favorites-sync\`：
  - 设置、上次同步结果、缺失快照：通过 Folia 官方 `storage` 保存（`mod-data.json`，上限 1 MB）；
  - 日志 `lx-favorites-sync.log`（超过 1 MB 轮换一份，旧档 7 天后自动清理）；
  - 同步备份 `backups/`（最多 30 份，只在收藏真的发生变化时写入）。

模组**不写** Folia 的 `local_dir_handles`，不改动 Folia 的目录管理；本地音频文件不会被移动、删除或重命名。

## 隐私

模组不发起任何网络请求，不收集、不上传任何数据，只在你的电脑上读取上面列出的数据库与文件。

## 兼容性

- Folia：`>=0.7.17 <0.8.0`（需要开启实验性模组系统）。
- 平台：Windows 已测试；macOS / Linux 按 LX Music 的默认数据目录做了理论支持（未实测）。
- LX Music 数据目录非默认位置时，可设置环境变量 `LX_MUSIC_DATA_DIR` 指向包含 `lx.data.db` 的目录。
